# Table material maps

- [Marble016](https://ambientcg.com/view?id=Marble016), ambientCG, CC0.
- [Fabric038](https://ambientcg.com/view?id=Fabric038), ambientCG, CC0.

Color, OpenGL normal and roughness maps converted to WebP for browser delivery.
The fabric color map is desaturated for tinting in the scene.

## Form references

- [RIEDEL Veritas catalogue](https://restaurant.riedel.co.jp/user_data/assets/files/catalog/riedel_catalog_2024.pdf): bowl width and stemware proportions.
- [Pedrali Babila](https://www.pedrali.com/en-us/products/lounge-chairs/babila-2749): upholstered shell and separate cushion.
- [Flos Bellhop technical drawing](https://japan.flos.com/wp-content/uploads/2020/06/BELLHOP.pdf): scale and assembly of a portable table light.

All furniture and tableware meshes used here were built for the project. Catalog photographs and technical drawings are reference links only.
